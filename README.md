# 下班星空

点点天空，随便发光。一个工作结束后可以随手玩的小星空。

## 怎么玩

下载仓库后，用 Chrome、Edge 或 Firefox 打开 index.html 即可，无需安装依赖。

- 点击或轻触天空，点亮一颗星。
- 点击「添颗星」，也能随机添星；支持键盘操作。
- 距离较近的星星会连成小星座。
- 星星保存在当前浏览器本地，刷新后可以继续；最多保留最近 80 颗。
- 跟随系统的浅色或深色外观，并遵循减少动态效果设置。

## 文件

index.html 包含完整页面、样式和交互代码，可直接作为静态网页使用。

无需登录，不需要 API 密钥。星空保存仅使用浏览器本地存储。
